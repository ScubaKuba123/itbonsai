# Google Search Console — ITBonsai measurement checklist

## Setup

1. Verify the canonical `https://itbonsai.pl/` property.
2. Submit the canonical XML sitemap.
3. Inspect these URLs manually after each important SEO release:
   - /
   - /strony-internetowe-gdynia
   - /strony-internetowe-gdansk
   - /strony-internetowe-trojmiasto
   - /strony-internetowe-dla-firm
   - /cennik
   - /aplikacje-dla-firm
   - /automatyzacje-ai-dla-firm
   - /seo-techniczne
   - /realizacje
4. Confirm Google-selected canonical matches the intended canonical.

## Weekly review

For each priority URL record:
- impressions
- clicks
- CTR
- average position
- top queries
- top countries/devices only when useful

## Cannibalization review

Look for the same query producing significant impressions for multiple pages.

Priority query clusters:
- strony internetowe gdynia
- strony internetowe gdansk
- strony internetowe trojmiasto
- strony internetowe dla firm
- tworzenie stron internetowych
- aplikacje dla firm / aplikacje webowe
- automatyzacje ai dla firm
- seo techniczne
- koszt strony internetowej

Do not automatically merge pages merely because both receive impressions. Compare intent first.

## Decision rules

**High impressions + low CTR:** review title/snippet and intent match.  
**Position 8–20 + relevant query:** strengthen page depth, proof and internal links.  
**No impressions after indexing:** inspect canonical/indexing and reconsider whether the page deserves to exist.  
**Multiple pages for one query:** check cannibalization.  
**Traffic with no enquiries:** improve offer clarity, proof and CTA rather than adding more SEO copy.

## Core Web Vitals

Monitor mobile first. Investigate regressions after adding hero effects or large portfolio media.

## Review cadence

Do not make major SEO changes every day. Review meaningful Search Console trends over a longer window and annotate major releases.
