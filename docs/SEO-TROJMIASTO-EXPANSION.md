# Trójmiasto landing page — expansion brief

## Current problem

The live Trójmiasto page is substantially shorter than the Gdynia and Gdańsk pages. It should not become a third copy of the same local landing template.

## Recommended positioning

**Primary intent:** website design for businesses operating across Gdańsk, Gdynia and Sopot.

## Suggested H1

Strony internetowe dla firm działających w całym Trójmieście.

## New section 1 — Jedna firma, kilka lokalnych rynków

If a company serves more than one city, the website should explain the real service area once and then use useful local context where it helps the customer. Avoid creating three near-identical descriptions of the same offer.

## New section 2 — Jedna strona czy osobne landing pages?

Create separate local pages only when there is genuinely different information: service availability, case studies, location details, customer needs or search intent. If the offer is identical, one stronger page is usually cleaner than several weak copies.

## New section 3 — Widoczność lokalna bez doorway pages

Explain:
- service-area clarity,
- Google Business profile,
- consistent contact details,
- local proof/projects,
- internal linking,
- useful location context,
- technical indexability.

## New section 4 — Projekty i branże w Trójmieście

Use real or clearly labelled concept work. Suitable categories:
- hospitality,
- gastronomy,
- sport and local services,
- B2B,
- expert services.

Do not invent performance metrics.

## Internal links

Trójmiasto → Gdynia  
Trójmiasto → Gdańsk  
Trójmiasto → strony internetowe dla firm  
Trójmiasto → realizacje  
Trójmiasto → cennik

Gdynia / Gdańsk should link back to Trójmiasto only where the user actually serves the wider area.

## Quality gate

The page should still make sense if every city name were removed. If not, it is too dependent on location-keyword repetition.
